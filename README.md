# Jelly Fruit

Мобильный прототип гиперказуальной React-игры: квадратные фрукты с упругой деформацией падают в стеклянный контейнер. Два одинаковых кубика сливаются в следующий фрукт; цель — арбуз **2048**.

## Запуск

```sh
npm ci
npm run dev
```

```sh
npm test          # проверки физики и правил
npm run build    # TypeScript + production-сборка в dist/
npm run preview
```

Браузерные проверки выполняются отдельно при запущенном сервере:

```sh
npx playwright install chromium
npm run test:browser
# Для уже установленного Chromium:
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
# Для проверки production-сборки или вложенного пути Pages:
GAME_URL=http://localhost:4173/2048Game/ npm run test:browser
```

## Управление

- Игра начинается с пустого контейнера; числовых бейджей на фруктах нет.
- Веди пальцем и отпускай для броска. На компьютере — мышь и клик.
- Стрелки ← / → прицеливаются, пробел / Enter бросает, когда игровое поле в фокусе.
- Три встряски на игру бесплатны; дополнительная стоит 125 монет. Каждое слияние приносит от 1 до 10 монет в зависимости от ступени нового фрукта.
- Кубики выше пунктирной линии заканчивают игру после 1,2 секунды переполнения, даже если стопка продолжает двигаться. Новый или слившийся кубик получает 1,3 секунды на падение; красная полоса показывает отсчёт.
- Рекорд, монеты и настройка звука, покупки и выбранное оформление сохраняются локально. Открытые желешки относятся только к текущему раунду: новая игра и перезагрузка начинают список заново. Крупная лента фруктов прокручивается пальцем и стрелками; неоткрытые фрукты показаны чёрными силуэтами. Есть настройка звука, полный экран, справка, баланс монет и подтверждение перезапуска. Открытые окна приостанавливают физику.
- Лента имеет инерцию, сопротивление на краях и пружинный возврат. На компьютере также доступны перетаскивание мышью, колесо, стрелки и Home / End при фокусе на ленте. Её края плавно затухают.

## Физика и производительность

Фрукт — физическое мягкое тело: восемь точек по контуру и одна в центре, 20 упругих связей и ограничение площади. Verlet-интеграция и XPBD-связи сохраняют объём, дают граням прогибаться при ударе и постепенно возвращают квадратную форму. Контакты рассчитываются по текущему деформированному контуру, давление распределяется на его ближайшие точки. Ограничитель формы предотвращает складывание и чрезмерное растяжение при переполнении.

Физика работает с фиксированным шагом 60 Гц и шестью итерациями решения. Пространственная сетка отбирает только соседние пары. Успокоившиеся тела засыпают. Спрайт следует тем же восьми точкам через восемь текстурированных треугольников. Для каждого фрукта измерены границы видимой мякоти: прозрачные поля не уменьшают текстуру относительно коллайдера, листья продолжаются за его пределами. Деформированный спящий фрукт кэшируется по границам отрисовки и затем рисуется одним вызовом. Отдельный Matter.js больше не нужен.

Canvas ограничен DPR 2; за кадр выполняется максимум три шага. Скрытая вкладка приостанавливает симуляцию. Частицы ограничены, количество тел ограничено 70. Достижение лимита тел также запускает отсчёт переполнения, чтобы игра не зависала с заблокированным броском. React обновляет интерфейс по игровым событиям, без покадрового ререндера. У страницы нет прокрутки, выделения текста, перетаскивания картинок и контекстного меню. Поддерживаются безопасные области телефона, изменение ориентации и встраивание по относительному пути.

Превью верхнего фрукта следует прицелу через отдельную визуальную пружину и наклоняется по направлению движения. Физический бросок остаётся вертикальным и происходит в точной позиции прицела. Контроллер ленты `src/ui/ElasticScroll.ts` запускает кадры только во время движения и обновляет DOM без покадрового React-рендера. Анимации появления панелей, нажатий, счёта, очереди и открытия фруктов сделаны в CSS; окна сохраняют содержимое и паузу до конца анимации закрытия. Настройка `prefers-reduced-motion` уменьшает движение интерфейса и отключает инерцию превью. Фон — один чёткий слой на весь экран. Для каждого пейзажа сгенерирован отдельный широкий вариант с продолжением сцены по бокам; горизонтальная ориентация выбирает его автоматически. У масштабируемого игрового интерфейса нет отдельного фонового прямоугольника, поэтому на телефоне не видны края сцены.

## Ассеты

`public/assets/` содержит фруктовые спрайты, фоны со столешницей, стеклянные контейнеры и частицы. Все изображения включены в проект; внешний CDN не требуется. Из `public/assets/ui/generated/` интерфейс использует 26 отдельных растровых иконок, включая сгенерированный коралловый крестик. Красная корзина магазина стоит на небольшом чёрном полупрозрачном круге; жирная белая подпись с чёрной обводкой немного заходит на корзину, новые имена файлов корзины и крестика обновляют ранее сохранённые в браузере изображения. Кнопки, панели, окна, счёт и рамки фотографий сделаны на HTML/CSS без обводок. Скругления задаёт CSS-свойство `corner-shape: squircle` вместе с `border-radius`; старые WebView используют обычный `border-radius`. Старые текстуры сохранены как исходные ассеты, но больше не загружаются и не используются в UI. Игровые разделы занимают фиксированные строки сетки, длина чисел не меняет их размеры. Звуки синтезируются Web Audio; Nunito 700/800/900 с кириллицей поставляется локально через Fontsource. Желейность фруктов создаёт движок, максимум частиц — 150.

Полноэкранная стартовая загрузка показывает реальный прогресс изображений и шрифтов. Управление включается после загрузки всех ресурсов; при ошибке можно повторить загрузку. `scripts/prepare_assets.py` экспортирует фрукты и иконки, `scripts/prepare_polish.py` — вывеску и частицы, `scripts/prepare_shop_assets.py` — новые коллекции и измеренные квадратные границы тел из исходных сгенерированных изображений. `scripts/refresh_visual_assets.py` экспортирует отдельные новые фоны и исправленные спрайты, измеряя границы самого персонажа. Убраны фрагменты соседей в десяти спрайтах, огурец получил бугорчатую кожицу, усик и цветок. Начиная с драконьего фрукта спрайты перегенерированы, а их UV-контуры исправлены: квадратная лицевая часть масштабируется одинаково по обеим осям.

`src/game/fruits.ts` задаёт 11 ступеней 2 → 4 → … → 2048, размеры и цвета. `src/game/physics.ts` содержит правила и физический мир, `renderer.ts` — отрисовку, `audio.ts` — звуки. Исходный файл `Frame 44.webp` из репозитория сохранён.

## Магазин и награды

- Двенадцать коллекций по 11 квадратных персонажей, всего 132 кубика: фрукты, шушистики, суши, овощи, фастфуд без брендов, кристаллы, лунные моти, конфеты, выпечка, мячики, сонные подушки и космические сладости. Кролик и сова перегенерированы с квадратным телом; все 11 моти смотрят прямо. Новые коллекции имеют измеренные UV-контуры без растягивания исходного изображения.
- Восемь отдельных фонов: тёплый луг, сакура на закате, лунный сад, сладкие холмы, снежные вершины, сияющий сад, лазурная лагуна и звёздная кондитерская. Каждый создан отдельно с широкой столешницей и имеет второй пейзаж для горизонтального экрана. Девять вариантов контейнера. Магазин занимает весь экран: на одной вертикальной странице идут персонажи, затем фоны и боксы. Фон магазина — сама приостановленная игра, размытая через `backdrop-filter`, с лёгкой кремовой подложкой. Каждая конечная лента содержит один экземпляр товара и останавливается на первом и последнем; стрелки на границах отключаются. Квадратные CSS-карточки оформлены как фотографии Polaroid, между карточками — 28 px. Боковые фотографии постепенно уменьшаются по мере удаления от центра и слегка наклоняются; лёгкая волна проходит слева направо. Все трансформации применяются только к внутренней фотографии, геометрия ленты измеряется при изменении размера. Прозрачность и слои карточек остаются стабильными при быстрых сменах направления; волна приостанавливается во время жеста. Превью плавно появляются после декодирования изображения. При открытии каждая лента центрируется на надетом оформлении. Каждый раздел имеет фиксированную высоту 466 px и отдельные строки для заголовка, ленты, описания, пагинации, действий. Покупка или смена товара не сдвигает другие разделы. Цена и прогресс видео находятся под выбранной карточкой. Один горизонтальный свайп переключает не больше одной карточки. Скорость движения снижена, докрутка отменяется новым жестом; вертикальный жест над карточками прокручивает страницу. На компьютере доступны перетаскивание, горизонтальное колесо или Shift + колесо, стрелки клавиатуры, Home / End и кнопки навигации. Кнопка «Играть» всегда доступна внизу, баланс — вверху. Под шапкой закреплены переходы к персонажам, фонам, боксам, наборам и монетам. Единая плашка плавно перемещается между вкладками, нажатая вкладка остаётся выбранной на время перехода; при ручной прокрутке раздел определяется по области около середины экрана; рядом находится компактная фиолетовая кнопка «+150» за видео.
- Обычное оформление можно купить за монеты или открыть после 2–4 добровольных видео. Прогресс открытия сохраняется, все карточки доступны для примерки, а постоянный выбор сохраняется только для принадлежащего игроку оформления. При применении загружается выбранный набор, затем атомарно меняются текстуры и UV; весь каталог не загружается на старте.
- Отдельный раздел ежедневных наград содержит цикл из 21 подарка в анимированной сетке: первые семь — 25 монет, 2 встряски, 60 монет, эксклюзивное лунное стекло, 120 монет, фон с северным сиянием и 11 лунных моти. На второй неделе — 80 монет, 3 встряски, 150 монет, 4 встряски, 220 монет, 5 встрясок и кристальная коллекция. Третья неделя: 180 монет, 3 встряски, 240 монет, эксклюзивный облачный бокс, 300 монет, 5 встрясок и эксклюзивные сонные подушки. За первый цикл выдаются 1375 монет, 22 встряски и шесть оформлений. Подарки седьмого, четырнадцатого и двадцать первого дней занимают широкие ячейки; получение сопровождается анимацией и обновлением шкалы прогресса. Один подарок за местный календарный день устройства; пропуск дня не сбрасывает прогресс. Сохранённый прогресс старого семидневного цикла продолжается во второй неделе. В следующих циклах уже открытое оформление заменяется монетами. Новые ассеты экспортирует `scripts/export_daily_assets.py`.
- Магазин предлагает три набора с оформлением и встрясками. Цена уменьшается, если часть оформления уже открыта; набор покупается один раз. В разделе монет и встрясок доступны 300 монет за два завершённых видео, встряска за видео, а также 1 встряска за 125 монет или 5 за 500. Дополнительные встряски сохраняются в профиле между играми; сначала тратятся три бесплатные за текущую партию, затем сохранённый запас, затем монеты.
- Наборы показывают крупного персонажа, фон и бокс, перечёркнутую обычную цену и скидку. Нажатие на любое оформление переводит к его разделу и центрирует именно эту карточку. Диагональные красные CSS-ленты отмечают новые коллекции и выгодные предложения. Карточки наборов занимают фиксированные 344 px; покупки не меняют геометрию соседних разделов. Иконки рекламы сохраняют исходные цвета, лишние подписи внизу магазина удалены. Магазин и награды быстро выезжают снизу и уезжают обратно; выход сохраняется также при переключении обычных окон и закрытии рекламы. Карточки появляются один раз сверху вниз через `IntersectionObserver`, оставаясь скрытыми до начала появления, смена товара и нажатия получают короткие CSS-анимации; `prefers-reduced-motion` сохраняется. Стрелки магазина используют одну зеркальную иконку. Уведомления появляются сверху, закрываются кнопкой или смахиванием вверх/вправо. Фон в ежедневных наградах обрезается и оформляется как фотография в магазине. Новый крестик экспортирует `scripts/export_close_icon.py`.
- После проигрыша можно один раз убрать верхние кубики и продолжить за видео. Полученные за текущую игру монеты можно удвоить один раз; бонус фиксируется отдельно, поэтому продолжение после победы не удваивает будущие начисления.

Реклама сейчас **имитируется**: окно явно подписано, просмотр длится 3 секунды, его всегда можно закрыть. Отмена не даёт награду; завершение выдаёт её однократно. Скрытая вкладка останавливает отсчёт. Покупки, кошелёк, дневной подарок и прогресс видео сохраняются в localStorage; для реальной площадки потребуются SDK, проверенное событие завершения rewarded video и серверное/платформенное сохранение. `RewardedAd.tsx` — точка замены имитации на SDK; `completeAd` проверяет уникальный запрос перед начислением.

`npm test` проверяет четырнадцать ежедневных призов, защиту от повторного получения, эксклюзивное оформление, цены и однократную покупку наборов, сохранение запасов, переполнение движущейся стопки, восстановление крупных тел, однократное спасение/удвоение, покупки и сохранение прогресса. `npm run test:browser` также проверяет магазин и применение всех трёх типов оформления, отмену/полный просмотр видео, открытие скина после трёх видео, дневные подарки, надевание эксклюзивного бокса, закреплённую навигацию, движение плашки и прерывание переходов, переходы к товарам из наборов, быстрые обратные свайпы, отсутствие повторного исчезновения карточек, смахивание уведомлений, наборы и пополнение запасов, а также реальные броски до проигрыша.

## GitHub Pages

Workflow `.github/workflows/pages.yml` запускается при push в `main`: `npm ci` → тесты → сборка → загрузка артефакта → деплой Pages. Pull request выполняет проверки и сборку без публикации. Vite использует `base: './'`, поэтому игра работает и на `/2048Game/`.

Игра опубликована по адресу https://calloradc.github.io/2048Game/.

Прототип не содержит рекламного SDK, платежей или зависимости от конкретной игровой площадки. Сборку `dist/` можно использовать как статическую HTML5-игру.

Верхние предложения магазина листаются пальцем и точками, автоматически сменяясь раз в 4,5 секунды. Просмотр содержимого и рекламы, скрытая вкладка и активный жест приостанавливают автолистание. Тап по карточке открывает мини-окно: все 11 персонажей скина, крупный фон или бокс либо три предмета и встряски набора. Кнопка просмотра содержимого убрана. Предметы в окне набора ведут к соответствующей карточке магазина; свайп не вызывает тап.

Цены оформления, бандлов и встрясок увеличены в пять раз. Монеты за рекламный просмотр удвоены: 150 за одно видео и 300 за два. Копилка также предлагает рекламный бонус. Купленный предмет и все предметы купленного бандла экипируются сразу. Центральная карточка примеряет оформление без отдельной кнопки; купленный предмет сохраняется, а закрытие на неприобретённом восстанавливает выбор этой категории, сделанный до открытия магазина. Быстрые примерки используют последнюю запрошенную комбинацию и отменяют устаревшую загрузку.

Кнопка магазина и «Следующий» находятся в отдельном игровом ряду и не участвуют во встряске куба. Подсказка под кубом удалена. Лента желешек использует одну иконку для обоих направлений с зеркальным отражением слева. Вертикальная прокрутка магазина, подарков, мини-окон и остальных диалогов использует ту же инерцию и пружину на границах, что и лента желешек; вертикальный жест над карточками передаётся странице. Большие окна проходят весь путь от нижнего края экрана без раннего исчезновения. После каждого проигрыша появляется предупреждение на 2 секунды, затем демонстрационная межстраничная реклама на 3 секунды без награды. Отсчёт идёт только в видимой вкладке. Затем доступны действия с результатом игры; повтор появляется через секунду. Показ не начисляет монеты и не меняет результат. Рекламного SDK в прототипе нет.

Баланс отображается компактно латинскими суффиксами K/M/B/T (1543 → 1.5K). У рекламных предложений остаются только точки навигации, подпись автоматической экипировки удалена. Вертикальная прокрутка быстрее реагирует на колесо и жесты; растяжение у краёв ограничено, размеры содержимого кешируются при изменении геометрии.

Новые базовые боксы сгенерированы каждый отдельно с лунным боксом как референсом формы: чистое стекло, сакура в фарфоровой оправе, медовые деревянные соты, гранёный лёд, бамбук и неоновая аркада. Лунное стекло сохранено. Облачный бокс выдаётся за 18-й ежедневный подарок; сонные подушки — за 21-й. Космические сладости, звёздная кондитерская и орбитальный бокс доступны исключительно в новом космическом наборе за 4400 монет с 7 встрясками. Лазурная лагуна доступна отдельно. Источники 28 генераций записаны в `scripts/autumn-assets.json`, экспорт — `scripts/export_autumn_assets.py`.

Экран загрузки использует сгенерированную обложку с реальным прогрессом ресурсов и отдельной широкой версией. Все восемь фонов имеют второй пейзаж для горизонтального экрана. Горизонтальная компоновка раскладывает счёт и управление по бокам крупного контейнера; магазин и подарки немного шире. PWA поддерживает обе ориентации. Настройка вибрации убрана, отступ под шестерёнкой увеличен. Вертикальная пружина использует устойчивое затухание и малое растяжение без накопленного хода за границей. `scripts/refresh-smoke.mjs` проверяет тап, один товар за свайп, смену направления у обеих границ магазина и подарков, новые эксклюзивы и поворот телефона.
